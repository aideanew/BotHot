## 3. 恢复命令（有凭据时执行）

```bash
cd /d/Code/AideanBotHot

# ① 确认要推的两个提交还在
git log --oneline -3          # 期望看到 fb43ba4 / 8614365 / 1eaf2d5

# ② 配一个可用的凭据（三选一）
#    甲：Personal Access Token（最省事，作用域只需 repo）
git config --local credential.helper store
printf 'https://<用户名>:<PAT>@github.com\n' > ~/.git-credentials

#    乙：SSH（需先把公钥加到 GitHub）
git remote set-url origin git@github.com:aideanew/BotHot.git

#    丙：让 GCM 在有界面的终端里弹一次窗，登录后凭据进 Windows 凭据管理器

# ③ 推送并核对双端
git push origin main
git ls-remote origin -h refs/heads/main   # 应与 `git rev-parse HEAD` 同 sha
```

**不要做的事**：不要 `git push --force`；不要为了「推上去」把两个提交 squash 成一个——
`8614365` 的代码与 `fb43ba4` 的文档是两类变更，合起来会让「代码改动有没有牵动 CI」不可分。
