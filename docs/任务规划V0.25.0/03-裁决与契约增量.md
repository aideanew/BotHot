## 4. 为什么本版没有「双向召回清单」

V0.24.0 `03` §4 那张表是给**改产品文案**的卡准备的（被新串遮蔽的旧断言才是真陷阱，P-145）。
本版两卡都**不改任何产品文案**：74 只改一条测试断言的正则，75 只改测试与环境读数。
⇒ 无新串、无被取代的旧串，该表在 V0.25.0 是空集，不是省略。

**唯一需要「双向」的地方是 74 的反向验证**：改完之后必须证明它**仍然会红**（把正则临时改回宽式复跑一次），
否则「变绿」可能只是断言被改废了——那条证据收在 `EVD-V25-74/`。
