## 3. 本规划的前提

1. **`df210b3` 就是执行基线**，且它只改 `docs/**`（F-1 已证：`3c4138d..HEAD` 非文档变更 0 个文件）。若后续有人在其上叠业务代码，本版卡面的行号要重取。
2. **`playwright.config.ts` 的 `real` project 不扩 `testMatch`**（现读只收 `(admin|r19-chat-stream)\.spec\.ts`）。若扩，60 的读数面变大。
3. **`middleware.ts` 的 307 落点不改**（D-V23-15）。
4. **V0.24.0 的六张卡面不被推翻**：本版只加两卡与三处订正，不代它们做决定。
