本版的 G-PLAN 自律门：**规划产物入库前，敏感形命中必须为 0**。判据指向仓内既有扫描器，不在文档里内联正则或样例（这条纪律的来源就是本版抓到的自伤，见 F-09）。

# 打码后实测：文件数 43，HIGH 0（此前有 1 处）

## 4. 双端一致（推送与自证）

```bash
git fetch origin main
git rev-list --left-right --count origin/main...HEAD     # 推送后期望 0 0
git rev-parse HEAD origin/main                           # 两个哈希必须相同
git log --oneline -1
```
远端不可达时的降级：`git archive` 出 zip（本轮可达，未触发降级；zip 仍作附加交付同时提供）。
