# Product Goals — BotHot

## 核心目标

### G1. 多渠道推送闭环
用户配置机器人渠道后，系统自动将知识库内容（新文章 / 热点 / 日报）推送到飞书/钉钉/企业微信等渠道，支持定时和事件触发。

### G2. 热点感知能力
对入库文章进行主题聚簇、热度评分，生成 Feed 流和每日日报，让用户无需翻看全部文章即可掌握热点动态。

### G3. 知识库管理（继承）
保留 AideanBot 的核心能力：公众号链接解析入库、LangBot RAG 知识引擎、多空间隔离、公共库共享、整号订阅增量同步。

### G4. 可插拔引擎架构
知识库引擎支持 builtin / langbot / aidean / redfox 多后端切换，新增引擎零迁移。

### G5. SSO 统一认证
作为主平台的子平台，通过 OIDC 接入主平台统一账号，身份锚点 = users.sub。
