## 0. 目标（一句话，可验证）
admin 与 operator（STEP-25 之后）调用 `POST /api/v1/bots/tasks` 在真库上返回 `200/0`，落库 `push_tasks.created_by == 当前登录者 users.id`，且请求体里任何 `created_by` 都不改变归属。

## 1. 5W1H（压缩）
- **What**：`bots.py:325` `created_by=payload.created_by or "system"`；列 `bothot_entities.py:88-90` 为 `users.id` NOT NULL FK；前端 `PushTasksTab.tsx:180` 传 SSO sub，`lib/api/bots.ts:164` 标为可选 ⇒ 两条路径都违反 FK。
- **Why 没被发现**：`git grep -n "bots/tasks" apps/api/tests | grep -i post` 0 条连库用例；前端默认 mock（`http.ts:18-19`）遮蔽真实后端。
- **Who**：受影响 = 全部运营/管理员；越权面 = 任何能建任务的人可把归属写成任意本地用户。
- **What if**：只改兜底字面量为某个固定 admin id ⇒ 500 消失但归属被伪造的问题仍在（反方案，否决）。
