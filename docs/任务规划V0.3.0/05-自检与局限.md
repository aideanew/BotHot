## 3. 前提与局限

1. 测试结果来自本沙箱（aarch64 Linux、conda PG16、存在环境代理），不是开发者 Windows 机器，也不是 CI。代理导致的失败已用对照实验证明，但 CI 最新结论未查（U-07）。
2. Redis、LangBot 未起：5 条 skip 涉及的路径本次未验证。
3. 前端零改动，未复测（沿用 V0.2.0 记录）。
4. 4 家付费源的“上游形状”只有样本（由 client 读取路径导出），无活体响应；B-2 行数为样本行数。
5. 生产数据规模未知，STEP-07 的工作量可能从“零回填”到“大量冲突”不等。
6. 人日估算基于本次代码阅读，不是历史速度数据；仅供排期参考。
7. 契约中 `ArticleKey` 的 pattern 当前写的是方案 A，若裁决为 B 需在 STEP-01 改写。
