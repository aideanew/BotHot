后端（`apps/api`）：`ruff check app tests` → `mypy app` → `alembic upgrade head` 且 `alembic heads` 只一个头 → `python ../../scripts/gen_contracts.py --check`（**本版你不应改到契约；不一致就停下交回**）→ 仓库根 `python scripts/check_docs_consistency.py` → `pytest tests/ -q -rs --cov=app --cov-report=json` 并跑 `python ../../scripts/check_module_coverage.py`；skip 不得超过 `ci.yml` 的 `SKIP_BASELINE`，不得有"PG 不可达"的 skip。
前端（`apps/web`）：`pnpm install --frozen-lockfile` → `pnpm run typecheck` → `pnpm exec tsc --noEmit -p ../../packages/contracts/tsconfig.json` → `pnpm run test:unit` → `pnpm run lint`；改页面加 `NEXT_PUBLIC_API_MOCK=false pnpm run build`。
新增连库用例：同步抬 `.github/workflows/ci-windows.yml` 的 `SKIP_BASELINE_WIN` 到测量值（不留余量；当前起点 692，STEP-47 已抬）。

### 六、敏感形门与 gitleaks
- 证据和文档里不要原样写"键名 + 等号 + 值"的样例，不贴门的输出片段与扫描正则；描述形状用文字。
- 测试里的凭据形假值一律运行时生成，源码里不写凭据形字面量。
- gitleaks 命中只许按 D-12 逐指纹登记，不许改规则、不许加通配豁免。

### 七、密钥与付费接口
- 五个采集源 key 只在用户保险库与规划方机器的仓库外文件里。命令、提交、证据、日志里不写任何 key 或 PAT；真 key 不进 `apps/api/.env`。
- 任何会真实调用付费接口的测试必须 mock 并断言次数。
- 推送用本机已配好的凭据；推不上去就停下问，不在命令行或 remote URL 里写 token；推送完成后按既有铁律清理临时凭据。

### 八、权限口径（不变）
- 角色门只写一个最低角色：`require_roles("operator")` 或 `require_roles("admin")`。
- 新写接口必须进 `apps/api/tests/test_push_and_hot_rank_matrix.py` 矩阵（user 必须 10004）。本版各卡均不新增接口。

### 九、必须停下交回的情况
1. 要改冻结契约（含 `apps/api/app/contracts/**`、`packages/contracts/**`、`scripts/gen_contracts.py`、稿目录），或要改卡面没写的业务代码。
2. 迁移出现两个头，或卡要新建迁移（本版零迁移）。
3. 先红做不出来，或行号漂移 >3 处。
4. 同一判据连续 2 次 FAIL（熔断）。
5. 需要只有用户能给的东西：生产只读 DSN、真实 key、凭据重置。
6. STEP-53 的 tag 推上去后任一工作流红：不删 tag，登记 P 号并交回。
7. 前端渲染依赖了契约里没有的字段（STEP-48/52）：登记 P 号交回，不改契约、不删渲染。
8. 发现卡面外新缺陷：从 **P-123** 起登记在 P 表，写事实、证据、复现、建议归属，不顺手修。上游安全公告的补丁级升级例外（D-V18-10）。
