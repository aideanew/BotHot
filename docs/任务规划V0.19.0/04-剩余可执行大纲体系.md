### 六、敏感形门与 gitleaks
- 证据和文档里不要原样写"键名 + 等号 + 值"的样例，不贴门的输出片段与扫描正则；描述形状用文字。
- 测试里的凭据形假值一律运行时生成，源码里不写凭据形字面量（STEP-19 第 2 轮的教训）。
- gitleaks 命中只许按 D-12 逐指纹登记，不许改规则、不许加通配豁免。
- 日志遮蔽相关证据只写"随机值出现次数 = 0"这类计数，绝不抄任何凭据或令牌原值。

### 七、密钥与付费接口
- 五个采集源 key 只在用户保险库与规划方机器的仓库外文件里。命令、提交、证据、日志里不写任何 key 或 PAT；真 key 不进 `apps/api/.env`。
- 付费正文兜底默认关；免费直抓永远先跑；任何会真实调用付费接口的测试必须 mock 并断言次数。TikHub 发现端点不核实、不花钱（D-V18-11）。
- 推送用本机已配好的凭据；推不上去就停下问，不在命令行或 remote URL 里写 token。
