## 3. 双端一致（推送与自证）

```bash
git fetch origin
git rev-list --left-right --count origin/main...HEAD     # 推送后期望 0	0
git status --porcelain                                   # 期望只剩 4 项第 2 批/未入库件
git log --oneline -2
```
