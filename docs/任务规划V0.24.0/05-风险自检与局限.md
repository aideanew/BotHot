## 2. 本规划的前提

1. **`3c4138d` 就是当前基线**，且 STEP-67 第 2 轮的改动（`.first()` / `exact:true` / `port_owner` 补 `return 0`）不会被后续回退。
2. **`emitDeclarationOnly` 不会变**（`packages/contracts/tsconfig.json`）。若哪天改成可产出运行时代码，`CHAT_COPY` 放 `lib/` 的理由消失，但放 `lib/` 也不违规。
3. **`chat.py` 的 LLM 调用面不会变**（`/chat/completions` + SSE `data: ` 行）。若改成 Responses API，STEP-72 的假 LLM 要重写。
4. **`middleware.ts` 的 307 落点不会被改**（D-V23-15 已裁）。若改，STEP-60 的 `unauthenticated` 用例要重写。
