## 一句话

V0.23.0 把「八态」从口头清单收敛成了 6 条可判的卡；本轮只处理它没收完的那一段——**`/chat` 的 5 个态**：契约自相矛盾（P-147）、产品三处没兑现（U-1～U-3）、测试用一条自指断言冒充覆盖（`r19-chat-stream.spec.ts:100-108`）。

## 本版范围（只做三件事）

1. **让契约自洽**：`ux_states.schema.json` 的 `definitions.State` 说「8 态、每视图必交 8」，而 6 个视图实际只列 5–7 个键、`NotificationBell` 还多一个 enum 之外的 `offstate`（P-147）。三方互斥时执行者选哪个都错一半——这正是 `r19` ④ 退化成「断言全部未测」的根因。
2. **让 `/chat` 兑现契约**：`loading` 要「思考中…」+ 可中断，`error` 要「连接中断，可重试」。现读前者写作「正在思考…」且**没有停止按钮**，后者**全站零命中**。
3. **让测试真跑**：`r19` 现只有 4 个用例，其中 ④ 断言「8 条全部未测」。换成逐视图真用例，并给它一条能跑通的供给链（假 LangBot + 假 LLM + 种子）。
