## 分类口径

- **行为面**：跑一段真实/仿真代码问「返回了什么、下发了什么条件」；迁 pytest 时可等价。
- **结构面**：AST/文本扫描问「这份源码长什么样」；多数**不可**等价进 pytest（CI 里没有这台机器）。
- **探针 / 反证 / 等价 / 自证**：判的是门禁自身的判定力与体面性，属**取证工具**，迁移时随脚本一起归档（S0T.3.1），不冒充业务用例。
- **前提/其它**：登记表在不在册、路径存不存在这类前置。
