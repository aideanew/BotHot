## 1. 台账登记规则（本版落的机械约定）
1. 每行字段：`ID / 问题 / 默认值(A) / 备选(B) / 登记时间 / 生效时间=登记+24h / 签字栏(空) / 推翻记录(空)`。
2. **登记 ≠ 签署**：规划/执行 Agent 可填前六列；签字列只能由人填。
3. BLOCKING 项（D-V3-01/03/06、D-V4-01/04、D-V6-01/02、D-V2-06）**不得因 24h 默认生效**，必须人签——沿用 V0.7.0 对 D-V2-06 的同类例外。
4. 任何卡不得以"等待裁决"停工超 24h（非 BLOCKING 项按默认值走）。

## 4. 决策台账的物理缺陷（仍未修，归 01 S1.1.0）
- 活目录只有 `adr-0001…0007`，`adr-index.md` 亦只列七条；**ADR-0008（契约唯一源，D-09 的依据）/0009/0010 只存在于 `docs/任务规划V0.1.0/03_solution/decisions/`**。
- 命名约定是小写 `adr-NNNN-kebab.md`，规划正文全写大写 `ADR-00NN`。
- ⇒ 本版 `decision-log.md` 里凡引用 ADR 的地方，一律同时给**路径**，避免"依据不存在的文件"。
