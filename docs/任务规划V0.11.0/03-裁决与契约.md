## 1. 台账登记规则（本版落的机械约定）
1. 每行字段：`ID / 问题 / 默认值(A) / 备选(B) / 级别 / 登记时间 / 生效时间 / 签字栏 / 推翻记录`。
2. **登记 ≠ 签署**：前六列任何 Agent 可填；签字列**原本**只能由人填——本轮由用户一次性授权"代选"，故其格式固定为「用户授权代选 / 日期 / 所选方案」，**不允许出现看起来像人名的签字**。
3. BLOCKING 项（D-V3-01/03/06、D-V4-01/04、D-V6-01/02、D-V2-06）**不得因 24h 默认生效**；本版它们生效的唯一依据是上面那条授权，且**授权不含需要外部凭据才能验证的部分**：D-V2-06 只代到"审计 → dry-run → 测试库带回滚实跑"，生产实跑仍是硬停。
4. 任何卡不得以"等待裁决"停工超 24h（本版起：BLOCKING 也已有生效值，这一条不再需要例外解释）。
5. 用户事后改判 = 只在该行"推翻记录"列写新方案，并回写受影响卡；**不回改历史 A/B 两列**（它们记录的是当时的选项空间）。
