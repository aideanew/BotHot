# 04 剩余可执行大纲体系（main@bad10d3）

层级：**一级 STEP**（一卡一文件）→ **二级 `Sx.y`** → **三级 `Sx.y.z`**（原子任务，单次提交可完成、可独立验收）→ 四级 `Sx.y.z.n`（执行步，不计数）。
29 张卡继承 V0.10.0（已随件复制，编号不复用、不重排）；本版**不增删功能任务**，只补两栏：**验收机标签**与**"机器不可用"分支**。

## 1. 本版对大纲的唯一结构变更
V0.10.0 的 183 个三级任务经复算自洽（F-10），因此本版不动任务数；动的是**每条验收命令必须回答"在哪台机器上跑"**：

| 标签 | 含义 | 判定 |
|---|---|---|
| `@win` | 这台 win32 规划机可跑（静态、git、纯 stdlib） | `git`/`grep`/`find`/`wc`/`python -` 且不需 venv |
| `@dep` | 需依赖机（venv+PG+Redis / `pnpm install` 成功） | 任何 pytest/ruff/mypy/tsc/vitest/playwright |
| `@ci` | 只有 CI 或 `gh` 能认定 | run 状态、run id、覆盖率门、skip 门 |

规则（D-V6-01，BLOCKING）：**卡内每条"验证命令"与"验收标准"必须带标签；未带的卡不得下发。** 缺标签的后果不是"跑不了"，而是**跑出 command-not-found 被当成失败或被当成通过**——两种都是假读数。

### 2.1 合计复算（禁手填；注意列名随版本变）
```bash
python - << 'PY'
import pathlib, re, glob
p = sorted(glob.glob('docs/*V0.11.0/04-*.md'))[0]
lines = open(p, encoding='utf-8').read().splitlines()
hdr = next(i for i,l in enumerate(lines) if l.startswith('| STEP'))
# 本版表：0 STEP |1 名称|2 里程碑|3 执行者|4 任务|5 人日|6 主验收机|7 状态
n=tot=0; days=0.0
for l in lines[hdr+2:]:
    if not l.startswith('| '): break
    c=[x.strip() for x in l.strip('|').split('|')]
    if c[0].startswith('**合计'): continue
    m=re.match(r'(\d+)', c[4].replace('*','')); b=re.match(r'(\d+(?:\.\d+)?)', c[5].replace('*',''))
    if m and b: n+=1; tot+=int(m.group(1)); days+=float(b.group(1))
print(f'行数={n} 任务={tot} 人日={round(days,2)}')   # 期望 29 / 183 / 28.25
PY
```
> **列位警告（本版实测）**：V0.9.0 表是"第 6 列任务、第 7 列人日"，V0.10.0/V0.11.0 是"第 5 列任务、第 6 列人日"，V0.8.0 又是 12 列布局。
> **同一脚本跨版必返回 0/0/0**。要跨版对照就按表头名匹配，别按位置硬取（本版已按名解析，故改用列位注释而非索引）。

## 10. 完成定义（全项目唯一口径，本版补一条机器维度）
Done = 所有权内 diff 符合任务 ∧ 每条验收**有本轮该机器现跑读数**（抄来的、上一时点的、别的机器的一律不算）∧ 命令带 `@机器` 标签且在该机器上可复现 ∧ 测试在 CI 可复现 ∧ EVD 让一周后的人不问作者能复现 ∧ 依赖机真实 ruff/gitleaks/全量 pytest 通过 ∧ 推送后 CI 与 Security 双 success（run id 入 EVD）∧ 复审 ≤2 轮（机械计数）∧ 判据自身做过变异反证（禁恒红/恒绿）∧ 未改冻结契约。
**明确不算 Done**：①假会话/AST 证明台 PASS；②无 PG 时 pytest **skip**（本机正是此形态，`conftest.py:106-107`）；③"本机跑不起来"换成"另一台机器说跑过了"而不标 `@ci`/`@dep`；④上一版读数抄成本版；⑤文档/注释声称已实现。
