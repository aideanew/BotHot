## 4. 双端一致（标准流程）
```bash
git fetch origin main
git pull --ff-only origin main                      # 快进前先验：入站文件 ∩ 在途脏文件 = 0
git add docs/任务规划V0.11.0 docs/03_solution/decisions/decision-log.md \
        docs/03_solution/decisions/adr-index.md docs/03_solution/decisions/adr-0011-canonical-article-key.md
git diff --cached --name-only | grep -v -e '任务规划V0.11.0' -e '03_solution/decisions'   # 期望无输出
git status --porcelain docs/03_solution/decisions            # 期望只剩本会话这三个文件
git commit                                          # 只带本会话路径
git push origin main
git fetch origin main && git rev-parse HEAD origin/main && git rev-list --left-right --count origin/main...HEAD   # 期望同哈希、0 0
git ls-remote origin refs/heads/main                # 直接问 GitHub，不信本地缓存
python -c "import zipfile;z=zipfile.ZipFile('../BotHot-plan-V0.11.0.zip');print(len([x for x in z.namelist() if not x.endswith('/')]))"
```
- 远端不可达时的降级：`git archive` 出 zip（本轮可达，未触发；zip 仍作附加交付同时给出）。
- 凭据：推送走本机既有 credential helper；**不把 PAT 写进 remote URL 或任何文件**。
