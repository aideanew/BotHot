## 4. 每步的验证协议（不可裁剪的四条）

1. **先红后绿**：任何行为/判据改动，先让新判据在未改代码上红，红输出原文入 EVD；不红的判据视为**未证明**。
2. **反证必须现跑**：结构守卫一律 AST（不用子串/正则——本会话实测被嵌套括号打败过一次），且每条守卫配"喂坏形状必须红"的自检。
3. **数字一律现算**：任何 `N passed / M skipped`、覆盖率、计数类结论必须由脚本产出后粘贴；本会话两次因此犯错（手填 138/8 实为 273/15；手填 422 实为 441），已立为纪律。
4. **读数必须可归因**：引用 run id 前核对 `head_sha ==` 目标提交（一次 push 带多个提交 ⇒ 只有尖端有 run）；`skip` 一律读族计数与 `pg_unreachable`，不读 `passed` 总数。
