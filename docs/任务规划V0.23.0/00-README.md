## 一句话

V0.22.0 的五张卡里 61（MeWallet 封闭）与 59（真后端 e2e 骨架档）已落地，60/62/63 未开。
本版**不新增功能面**，只做两件事：

1. **把"未被实现的需求"从口头清单变成可判的卡。** 逐条现读后确认，真正未实现的只剩三类：
   - **UI 八态契约里有 3 处没落地**（通知铃铛演示态静默、热点空态未拆且 0.0 显示成「0 分」、聊天降级无分流）；
   - **identity / chat 两域形状仍是手写**（契约包只到 6 域 + engine/shapes，这两域是 `.gitkeep`）；
   - **八态契约的唯一源还躺在 V0.12.0 冻结稿里**（P-80 自 V0.12.0 起无人认领）。
   4 引擎实接（D-V3-03）与 HOT-005 嵌入聚簇是**显式排除**，本版不动，只登记 BLOCKING 前提。

2. **建立统一规划体系。** 新增 `docs/任务规划-索引.md` 作单一入口：22 个历史版本一张表、
   卡片状态机词表、四套编号规则（STEP / P / D-V / EVD）、未闭合需求总表。本版登记进
   `docs/00_governance/project-map.md`，从此"读规划"有唯一入口，不必再 `ls docs/` 猜。
