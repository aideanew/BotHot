## 3. 依赖 DAG

```
64 ──► 65 ──┐
 └──► 66    ├──► 60 ──► 62 ──► 63
```

- **关键路径**：64 → 65 → 60 → 62 → 63。
- **可并行组**：`{65, 66}`。机械依据四条全满足：
  ① 无共享可变状态（65 只改 `apps/web/{components,app,lib/api/notifications.ts,tests}`；66 只改 `apps/api/app/contracts/shapes.py`、`packages/contracts/**`、`apps/web/lib/api/types.ts`）；
  ② 依赖的契约已冻结（65 用 64 产出的 `ux` 枚举；66 不改 `ux` 域）；
  ③ 文件所有权不相交（见 §4，`types.ts` 只归 66，`notifications.ts` 只归 65）；
  ④ 无迁移（本版零数据库迁移）。
- **必须串行的链**：64 → 66（同改 `scripts/gen_contracts.py` 与 `packages/contracts/src/index.ts`）；
  65 → 60（60 断言的是 65 修好后的 UI 态，否则 e2e 必红）；60 → 62 → 63。
- **环检测**：无环（6 节点 6 边，最长链 5，拓扑序唯一到 `{65,66}` 这一处分叉）。
