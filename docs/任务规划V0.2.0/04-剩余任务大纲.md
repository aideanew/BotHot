# 04 剩余任务大纲体系

## 4.0 编号与标记

- `S{n}` = 一级（对应 `steps/STEP-{n}-*.md`）；`S{n}.{m}` = 二级子目标；`S{n}.{m}.{k}` = 三级原子任务。
- 原子任务标记：🔴 先红（写失败测试/反证）｜🛠 实现｜✅ 验证｜📄 文档｜🗄 数据迁移｜👤 人工/裁决。
- 优先级：**P0** 数据正确性/崩溃｜**P1** 功能缺口｜**P2** 性能/可观测/治理。
- 每个三级任务的允许路径、验收命令、回滚见对应 STEP 文件；本页只给骨架与依赖。
