Q2 · 是否支持用户切换采集方式？ ◐ 分入口无统一切换

单篇/批量/公共库在空间详情页，整号在 /subscriptions 独立页，首次引导走 onboarding 三步三来源卡；无「按链接/按公众号」Tab 切换器，需求文档 U1 的「仅本篇/整库[置灰]」卡片未实现。对策：N4/N6 统一入口挂阶段 5。

Q3 · 能否采集公众号全部文章？ ❌

四环断链：清单实拉（1.1.2）→ Manifest 同步（1.2）→ Job 执行器（1.3）→ 增量调度器（1.4）。硬阻塞 = RedFox 积分 0.0（09-19 活体：Key 有效、3201 余额不足、单次 0.4 积分）——用户侧充值动作（→ D3）。

Q4 · 能否只采集一篇文章？ ✅ 活体验证

单篇 MVP 全链活体终验（09-13）：ingest 202 → 5 秒 READY → SSE 帧序 meta/citations/delta×12/done，引用带真实文章标题。幂等与质量分链路齐备。

Q5 · 能否绑定主流知识库（ima / 飞书·扣子 / Notion）？ ❌ 零集成 · 语义待裁决

业务代码 grep ima|feishu|lark|notion 仅命中 1 处注释（EngineSwitcher.tsx:8），零实现。现状是 RAG 引擎位而非知识库绑定：5 槽中仅 builtin(LangBot) 真实可用，main(RAGFlow)/coze/dify/fastgpt 六方法全 NotImplementedError（R1 三条件口径，ENGINE_IMPLEMENTED 仅 builtin=True）。三种语义对应三套工程（A 检索引擎 / B 导出归档 / C 采集来源），须先裁决主语义（→ D1）。

Q6 · 文章分类 + 免费公共信息输出？ ❌ 分类 ◐ 公共库

分类：entities.py 无 category/topic/tags 任何字段，前端零分类 UI（G6 → D5）。公共库：读端点 + copy 引入已实现；但 is_public 无任何写端点（只能 SQL 置位，不可运营），/public 是 36 行壳页且零导航入口。免费：需求明确不做计费 → 站内天然免费；对外公共输出渠道（公开页/API/推送）不存在（→ D5）。
