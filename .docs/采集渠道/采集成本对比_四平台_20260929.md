## 三、结论与选型建议

### 3.1 分场景最优

| 场景 | 首选 | 成本 | 理由 |
|---|---|---|---|
| **微信公众号采集** | tikhub | ¥0.0786 | 单价最低，轻量 JSON 详情仅 $0.001 |
| **微信公众号（需实时+HTML+视频）** | 极致了数据 | ¥0.17 | 官方实时数据、带 HTML、按次结算无美元汇率风险 |
| **抖音采集** | tikhub | ¥0.0143 | 价格碾压（比第二名便宜 50%） |
| **小红书采集** | Wellbyte 数井 | ¥0.1287 | 唯一在小红书赛道反超 tikhub |
| **B站采集** | tikhub | ¥0.0143 | 与抖音同价 |
| **多平台统一接入** | Wellbyte 数井 或 tikhub | — | 两者均覆盖四平台；Wellbyte 有原生 MCP，tikhub 单价更低 |

### 3.2 辩证提示（避免单一维度决策）

1. **低单价 ≠ 低成本**：极致了表观 ¥0.17 最优，但低频场景会触发"日消费补足 1 元"条款，实际可能远高于高阶平台。
2. **失败计费口径不同**：Wellbyte 明示"任何失败（含质量门槛未过）扣 0"，高频采集场景该规则可能显著降低成本，需纳入 TCO 而非只看单价。
3. **tikhub 的 $0.001 是地板价**：1462 端点中 994 个为此价（68%），但也存在 325 credits（Wellbyte 批量高清播放地址）/ $0.25（tikhub 高价端点）等长尾，实际采集需按端点核价。
4. **汇率与结算风险**：tikhub/Wellbyte 以美元结算，人民币口径随汇率波动；justoneapi/极致了为原生人民币，无此风险。
5. **数据合规**：四家均为第三方数据服务，采集内容的使用需自行确认授权边界。
